# LunchBox

Windows のタスクトレイに常駐して、**アプリごとによく使うファイル・フォルダ・URL をすぐ開ける**ようにするツールです。
「Excel のジャンプリストにピン留めしたファイルが、いつの間にか消えている」という悩みから作りました。

アプリにカーソルを合わせると、そのアプリの「ピン留め」と「最近使ったもの」がメニューで出てきます。
ほかにも、クリップボード履歴・検索・ウインドウ切替・ウインドウ配置の記憶・年度カレンダーなど、
毎日の作業を少し楽にする機能をまとめています。

## 主な機能

- **アプリごとのメニュー**：トレイアイコンかホットキー（既定 Alt+Shift+Y）でメニューを開き、アプリ → ピン留め／最近 の順にたどって開く
- **ピン留め**：ファイル・フォルダ・URL を登録。ドラッグ＆ドロップで登録・並べ替え。ラベルやメモも付けられる
- **「最近」の自動収集**：Excel・Word・PowerPoint の最近使ったファイル、エクスプローラーで開いたフォルダ、Chrome の履歴、Windows のジャンプリストから自動で集める
- **リンク切れ対策**：ファイルの移動・名前の変更をできるだけ追いかけ、見つからないときは選び直しを案内
- **アイコン表示**：アプリ・ファイル・サイトのファビコンを表示
- **クリップボード履歴**：文字と画像の履歴を保存（件数は設定で変更）。ピン留めもできる
- **検索ウインドウ**：ピン留め・最近・クリップボード履歴をまとめて検索
- **ウインドウ切替・マウスジェスチャ**：前面のウインドウを隠す／戻す、マウスジェスチャでウインドウ操作
- **ウインドウ配置の記憶**：モニターの構成ごとにウインドウの位置を記録し、つなぎ直したときに戻す
- **年度カレンダー**：4月始まりで36か月分を表示（祝日は内閣府の公開データを使用）
- **通知の表示先**：Windows の通知バナーを別のモニターに出す（既定はオフ）

機能はトレイメニューの「設定...」からオン・オフや細かい動きを変えられます。

## 動作環境

- Windows 10 / 11（64 ビット）
- 管理者権限は不要（必要なときだけ「管理者権限で常駐」を選べます）

## インストール

1. [Releases](https://github.com/ciel-works/LunchBox/releases) から `LunchBox_Setup_x.x.x.exe` をダウンロード
2. 実行してインストール（ユーザーごとのインストールなので、管理者権限は不要）
3. タスクトレイに LunchBox のアイコンが出たら完了

インストーラを使わない場合は、Releases の `LunchBox.exe`（単一ファイル）を好きな場所に置いて起動しても使えます。

> コード署名をしていないため、初回の起動時に Windows の SmartScreen の警告が出ることがあります。
> 「詳細情報」→「実行」で起動できます。

## 使い方

- **トレイアイコンを右クリック**（またはホットキー）：メニューを開く
- **トレイアイコンを左クリック**：検索ウインドウを開く（設定で入れ替え可）
- **アプリにカーソルを合わせる**：ピン留めと最近の一覧
- **項目を右クリック**：ピン留め／解除／編集／保存場所を開く などの操作
- **設定...**：アプリの追加、ピン留めの管理、ホットキー、各機能のオン・オフ

## データの保存場所

```
%AppData%\LunchBox\
```

設定（settings.json）、履歴、クリップボード履歴、アイコンのキャッシュ、ログを保存します。
アンインストールしてもこのフォルダは残るので、完全に消したいときは手で削除してください。

## 通信について

LunchBox が外部と通信するのは次の場合だけです。

- 祝日データの取得（内閣府「国民の祝日」CSV）
- URL のアイコン（favicon）の取得（そのサイトへアクセス）

履歴（Office・Chrome・エクスプローラー・ジャンプリスト）やクリップボードの内容は、パソコンの中だけで読み書きし、外部へ送ることはありません。

## FrontSwitcher から移行する方へ

LunchBox は FrontSwitcher の機能（ウインドウ切替・マウスジェスチャ・タブを閉じる・タスクバーから隠す）を取り込んでいます。
初回起動時に `%AppData%\FrontSwitcher\settings.json` があれば、設定を自動で引き継ぎます。

## ビルド

.NET 8 SDK が必要です。

```powershell
dotnet build -c Release
```

配布用（自己完結の単一 exe と、Inno Setup 6 があればインストーラ）：

```powershell
.\publish.ps1
```
